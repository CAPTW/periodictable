# Acceptance Checklist (DoD)

## 기능
- [ ] 앱 첫 실행 시 오프라인에서도 주기율표가 렌더링된다
- [ ] 원소 상세에서 필수 속성이 표시된다 (없으면 "N/A" 정책)
- [ ] 빠른 검색: 원소 이름/기호/원자번호가 동작한다
- [ ] 속성별 검색: 최소 1개 속성 필터(범위) + 정렬이 동작한다
- [ ] 속성 시각화: 리스트 또는 테이블 컬러맵 중 1개 이상 구현
- [ ] 메모: 원소별 메모 CRUD + 원소 상세에서 편집 가능
- [ ] 계산기: 화학식 입력으로 몰 질량 계산이 된다
- [ ] 용어집: 검색 + 상세 + 관련 링크 이동이 된다

## 품질
- [ ] `bash scripts/verify.sh` 통과
- [ ] 크래시 없이 기본 플로우(Table → Detail → Search → Calc → Glossary) 이동 가능
- [ ] 접근성: 원소 셀/버튼에 최소한의 contentDescription 제공
