# 프로젝트 규칙

- Kotlin + Jetpack Compose + Material 3
- Offline-first (네트워크 없이 동작)
- 필수 데이터 필드:
  - phase, electron configuration, molar mass, heat of vaporization, specific heat,
    thermal expansion, half-life, neutron cross section, barn, thermal conductivity,
    electronegativity, atomic radius
- 필수 기능:
  - 빠른 검색(이름/기호/속성 필터)
  - 원소 메모
  - 속성 시각화(리스트/컬러맵)
  - 몰 질량 계산기(화학식 입력 편의)
  - 화학 용어집(Interactive)
