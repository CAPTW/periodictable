# Phase 2E NaCl Smoke Summary

## 실행한 명령
1. **에뮬레이터 실행**:
   `emulator.exe -avd Medium_Phone_API_36.1 -netdelay none -netspeed full`
2. **앱 최신 디버그 빌드 설치**:
   `.\gradlew.bat installDebug`
3. **앱 구동**:
   `adb shell am start -n com.chemtable.interactive/.MainActivity`
4. **미니게임 탭 진입 및 시작**:
   - 하단 '시각화' 탭 (`Bounds: [495,2251][586,2297]`) 터치
   - 상단 '분자 만들기' 카드 (`Bounds: [32, 180][1000, 320] 부근`) 터치
   - 게임 인트로의 '시작' 버튼 (`Bounds: [506,1241][574,1294]`) 터치
   - '건너뛰기'로 튜토리얼 닫기
5. **자동 스와이프 매크로 구동**:
   - 무작위 방향으로 30회 스와이프하여 NaCl 합성을 유도하고 미션 타겟(H2O 2/2) 클리어를 통해 결과 오버레이 진입
6. **결과 화면 내 스크롤 다운**:
   - `adb shell input swipe 500 1250 500 900 300` 실행하여 만든 분자 목록 스크롤
7. **"염" 칩 터치 및 복귀**:
   - `Bounds: [222,1106][336,1190]` 터치하여 '사전 상세(GlossaryDetail)' 진입 확인
   - '뒤로가기' 버튼(`Bounds: [64,127][127,190]`) 터치하여 결과창 복귀 확인
8. **계산기 CTA 터치**:
   - '계산기에서 보기' (`Bounds: [590,880][833,913]`) 터치하여 'NaCl' 프리필 및 질량 계산 결과 확인
   - system back key로 결과창 복귀
9. **원소 칩 터치**:
   - Na 원소 칩 (`Bounds: [216,975][342,1059]`) 터치하여 '나트륨 (Na)' 원소 상세 화면 이동 확인

## 확인 결과
- **UI 텍스트 및 사전 192건 확인**: 용어 3종 추가가 완료되어 '사전' 검색 화면 진입 시 총 "검색 결과 192건"이 명확히 표시됨을 검증했습니다.
- **NaCl row 도달 및 우선순위 칩 노출**: 만든 분자 목록에 NaCl이 정상 노출되었으며, 칩 목록으로 `염`, `이온 결합`, `전기음성도` 3종만 우선적으로 표출되었습니다. 4순위 텀인 '화학식'은 3개 제한 규칙에 따라 정확하게 생략되었습니다.
- **"염" 용어 이동 및 복귀**: "염" 칩 탭 시 `염 (Salt)` 상세 페이지로 매끄럽게 연결되며, 정의와 쉬운 설명, 관련 원소(Na, Cl) 정보가 올바르게 렌더링되었습니다. 뒤로가기 버튼을 통해 결과 화면으로 성공적으로 복귀합니다.
- **계산기 CTA 프리필 연동**: '계산기에서 보기'를 눌렀을 때 몰 질량 계산기 화면으로 전환되며 포뮬러가 `NaCl`로 prefill되고 총 몰 질량 58.440 g/mol 및 Na1/Cl1 기여도가 즉각 계산되어 출력되었습니다.
- **원소 상세 이동**: 'Na' 원소 칩 클릭 시 원자번호 11 나트륨 원소 상세 화면으로 올바르게 네비게이션되었습니다.
